# РемонтПрофи — тема WordPress

Тема собрана из готового статического сайта (HTML/CSS/JS) и переносит весь его
контент (услуги, типы квартир, цены, отзывы, FAQ, 60 статей блога) в WordPress.

## Установка

1. Убедитесь, что установлен и активирован плагин **Advanced Custom Fields PRO**
   (используется только он — других решений для полей в теме нет).
2. Скопируйте папку `theme/` в `wp-content/themes/remontprofi/` (можно переименовать
   папку — имя каталога не имеет значения).
3. Активируйте тему в admin → Внешний вид → Темы.
4. При активации автоматически:
   - создаются все страницы сайта (услуги, типы квартир, цены, о компании,
     отзывы, вопросы и ответы, карта сайта, блог) с нужными шаблонами;
   - создаются все 60 статей блога с реальным текстом;
   - страница «Главная» назначается статической главной страницей сайта;
   - страница «Блог» назначается страницей записей (Настройки → Чтение).

   Если по какой-то причине это не произошло сразу (например, тема была
   активирована раньше ACF Pro), зайдите в любой раздел админки — недостающие
   страницы досоздадутся автоматически (см. `inc/inc-activation.php`).
5. Проверьте Настройки → Постоянные ссылки → «Сохранить» (обновляет rewrite-правила).
6. Настройте контакты в **Настройки сайта** (пункт меню в самом низу админки):
   телефон, email, ссылки на Telegram/MAX, рейтинг и цифры доверия.

## Как устроен контент

- **Картинки и тексты** редактируются через ACF на каждой странице/записи.
  Если поле не заполнено — используется значение по умолчанию из кода
  (перенесённое с исходного сайта), то есть сайт всегда выглядит наполненным,
  даже без единой правки в ACF.
- **SVG-иконки** (карточки преимуществ, стрелки, чек-листы) — только в коде,
  через ACF не редактируются (по условию задачи).
- Все повторяющиеся по сайту блоки — калькулятор ремонта, CTA-баннер
  «Просто позвоните», полоса доверия под заголовком, блок статистики,
  врезка в статьях блога со ссылкой на услугу, блок контактов, иконки
  мессенджеров — реализованы шорткодами (`inc/inc-shortcodes.php`):
  `[quiz_calculator]`, `[promo_banner]`, `[hero_trust]`, `[stats_block]`,
  `[cta_box]`, `[contacts_block]`, `[messenger_icons]`.

## Структура темы

```
theme/
├── style.css                 # обязательная шапка темы для WordPress
├── functions.php             # подключение всех inc/*.php, enqueue стилей/скриптов
├── header.php / footer.php   # общая шапка (мега-меню) и футер + кнопка «Онлайн-расчёт»
├── front-page.php            # главная страница
├── page-landing.php          # шаблон услуги / типа квартиры (используется 18 страницами)
├── page-hub-services.php     # «Все услуги» (каталог)
├── page-prices.php           # «Цены»
├── page-about.php            # «О компании»
├── page-reviews.php          # «Отзывы» (+ schema.org Review/AggregateRating)
├── page-faq.php              # «Вопросы и ответы» (агрегирует FAQ со всех страниц + FAQPage schema)
├── page-sitemap.php          # «Карта сайта»
├── page-blog.php             # список статей блога (посадочная страница записей)
├── single.php                # отдельная статья блога
├── 404.php, index.php        # служебные шаблоны
├── inc/
│   ├── inc-helpers.php       # rp_field()/rp_repeater()/rp_image_url() — ACF-значение или дефолт из кода
│   ├── inc-render.php        # функции вывода повторяющейся разметки (карточки, FAQ, цены…)
│   ├── inc-acf.php           # регистрация всех групп полей ACF Pro (локально, без JSON)
│   ├── inc-shortcodes.php    # шорткоды повторяющихся блоков
│   ├── inc-post-types.php    # размеры картинок, категория блога по умолчанию
│   ├── inc-activation.php    # автосоздание страниц/записей при активации темы
│   └── data/                 # PHP-массивы с контентом по умолчанию (перенесено с исходного сайта)
└── assets/
    ├── css/style.css         # вся вёрстка (без изменений от исходного сайта)
    ├── js/main.js             # меню, квиз-калькулятор, аккордеон, счётчики (без изменений)
    └── img/                   # фотографии и логотипы брендов-партнёров
```

## Что сознательно не сделано

- Мега-меню в шапке собрано вручную в `header.php` (а не через `wp_nav_menu` +
  Меню в админке) — так и структура, и переносимые ссылки на страницы полностью
  под контролем темы и не потребуют настройки меню после установки.
- «Карта сайта» группирует статьи блога одним списком (не повторяет 11 узких
  подкатегорий исходного статического сайта) — так проще поддерживать список
  в актуальном состоянии автоматически.
- Каталожные блоки (сетки карточек услуг на «Все услуги» и на главной) не
  редактируются через ACF — это списки ссылок на другие страницы сайта,
  а не самостоятельный контент.
