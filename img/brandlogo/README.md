Логотипы клиентов для бегущей строки на главной («Бренды, с которыми работаем»).

Положите сюда 8 файлов с именами `logo-1.svg` … `logo-8.svg`
(SVG предпочтительно; PNG подойдёт, но тогда поменяйте расширение в `index.html`,
в блоке `<div class="clients__marquee">` — там два одинаковых списка `<ul class="clients__list">`,
меняйте расширение в обоих).

Рекомендации по файлам:
- прозрачный фон, логотип по центру;
- одинаковая высота (лого впишется через `object-fit: contain`);
- вес каждого файла — до ~30 КБ, чтобы не терять в скорости загрузки.
