Логотипы брендов для бегущей строки на главной («Бренды, с которыми работаем»).

Сейчас в бегущей строке используются файлы из этой папки как есть — просто
любой формат (PNG/JPG/WEBP/SVG), имя файла свободное. Чтобы добавить или
убрать бренд, отредактируйте список `<li class="clients__logo">` в двух
местах `index.html` (в блоке `<div class="clients__track">` — там два
одинаковых списка `<ul class="clients__list">`, добавляйте/удаляйте строку
в обоих одинаково, порядок должен совпадать).

Рекомендации по файлам:
- прозрачный или белый фон, логотип по центру;
- вес каждого файла — до ~30–50 КБ, чтобы не терять в скорости загрузки.
